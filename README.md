# 🚗 ENGINEZ — Drive Clean, Drive Proud

A modern e-commerce website for premium car care products. Built with vanilla HTML, CSS, JavaScript, and Node.js.

---

## ✨ Features

- 🛍️ Product Catalog with search
- 🛒 Shopping Cart with quantity management
- 💳 Complete Checkout Flow
- ⭐ Product Reviews with star ratings
- 📦 Order Tracking (by email/phone)
- 📧 Contact Form with admin replies
- 👑 Admin Dashboard for managing orders and messages
- 📱 Fully responsive design

---

## 🛠️ Tech Stack

**Frontend:** HTML5, CSS3, Vanilla JavaScript, Font Awesome
**Backend:** Node.js, Express.js, Nodemailer
**Storage:** JSON files
